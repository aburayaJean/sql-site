Antes de sair escrevendo SQL, vale deixar a bancada arrumada. Nesta parte a gente escolhe a edição certa, instala o SQL Server (no Windows ou no Docker), conhece o SSMS de verdade, o VS Code e o sqlcmd, restaura bancos de exemplo e fecha com duas coisas que muita gente ignora: como os batches funcionam e como escrever SQL que outra pessoa consegue ler.

Cada post termina com prática, documentação oficial e indicações da comunidade.
